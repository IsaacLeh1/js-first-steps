# JavaScript First Steps

A hands-on introduction to JavaScript for people who have never written code. Everything is in one `index.html` file: open it in any browser and every example runs on the page. Nothing to install.

## Lessons

| Session | Lessons |
| --- | --- |
| 1. Foundations (50 min) | How the web fits together · Talking to the console · Variables · Math and text |
| 2. Logic (75 min) | Making decisions · Lists and loops · Functions · Objects |
| 3. The page (90 min) | Changing the page (DOM) · Reacting to clicks and typing · Project: a to-do list |

Each lesson has a runnable example, a common mistake and its fix, a challenge with hint and solution, and a quiz question. There's also a cheat sheet.

## For instructors

Turn on **Teaching notes** (top right) to see timing, talking points, and common questions for each lesson. Turn it off before sharing your screen if you'd rather learners not see them.

## Running it

- Open `index.html` directly, or
- Enable GitHub Pages (Settings → Pages → deploy from `main`) and share the link.
